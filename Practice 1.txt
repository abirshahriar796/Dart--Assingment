4. Find Simple Interest

Formula:
SI = (p * t * r) / 100

import 'dart:io';

void main() {
  print("Enter principal amount:");
  double p = double.parse(stdin.readLineSync()!);

  print("Enter time:");
  double t = double.parse(stdin.readLineSync()!);

  print("Enter rate:");
  double r = double.parse(stdin.readLineSync()!);

  double si = (p * t * r) / 100;

  print("Simple Interest = $si");
}

Output:

Enter principal amount:
10000
Enter time:
2
Enter rate:
5
Simple Interest = 1000.0

8. Swap two numbers
import 'dart:io';

void main() {
  print("Enter first number:");
  int a = int.parse(stdin.readLineSync()!);

  print("Enter second number:");
  int b = int.parse(stdin.readLineSync()!);

  print("Before swapping: a = $a, b = $b");

  int temp = a;
  a = b;
  b = temp;

  print("After swapping: a = $a, b = $b");
}

Output:

Enter first number:
10
Enter second number:
20
Before swapping: a = 10, b = 20
After swapping: a = 20, b = 10

11. Split restaurant bill among friends

Formula:
Split Amount = Total Bill / Number of People

import 'dart:io';

void main() {
  print("Enter total bill amount:");
  double bill = double.parse(stdin.readLineSync()!);

  print("Enter number of people:");
  int people = int.parse(stdin.readLineSync()!);

  double amount = bill / people;

  print("Each person has to pay = $amount");
}

Output:

Enter total bill amount:
2000
Enter number of people:
4
Each person has to pay = 500.0

12. Calculate time taken to reach office

Given:

Distance = 25 km
Speed = 40 km/hour

Formula:
Time = Distance / Speed

Then convert hours to minutes:

Minutes = Time × 60

void main() {
  double distance = 25;
  double speed = 40;

  double timeInHours = distance / speed;
  double timeInMinutes = timeInHours * 60;

  print("Time taken = $timeInMinutes minutes");
}

Output:

Time taken = 37.5 minutes
